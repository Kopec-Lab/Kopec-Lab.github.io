# Kopec Lab Website

Source code for the [Kopec Lab website](https://www.kopec-lab.com) — the research group of Dr Wojciech Kopec at Queen Mary University of London.

We work on molecular dynamics simulations of membrane proteins and ion channels, with a focus on potassium channel gating, selectivity, and computational electrophysiology.

---

## Live site

[kopec-lab.com](https://www.kopec-lab.com)

---

## Built with

- [Jekyll](https://jekyllrb.com/) static site generator
- [al-folio](https://github.com/alshedivat/al-folio) theme
- Hosted on [GitHub Pages](https://pages.github.com/)

---

## Running locally

```bash
# Clone the repo
git clone https://github.com/Kopec-Lab/Kopec-Lab.github.io.git
cd Kopec-Lab.github.io

# Install dependencies (first time only)
gem install bundler
bundle install

# Serve locally
bundle exec jekyll serve
```

Open `http://localhost:4000` in your browser.
